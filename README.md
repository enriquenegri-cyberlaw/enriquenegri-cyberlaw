## Práctica técnica actual

- Administración básica de archivos, rutas, permisos y metadatos en Linux.
- Uso de Git y GitHub para registrar cambios y mantener trazabilidad.
- Automatización inicial con Bash.
- Verificación de integridad de contenido y análisis básico de metadatos.
- Estudio de inodes, copias, hard links y enlaces simbólicos.
- Análisis defensivo de logs sintéticos, separando hechos observados, inferencias e hipótesis.

Cada práctica busca registrar el objetivo, los comandos utilizados, los resultados observados, la explicación causal, las comprobaciones y los límites de la conclusión.
